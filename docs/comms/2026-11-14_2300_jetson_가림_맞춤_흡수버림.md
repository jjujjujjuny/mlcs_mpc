## 1. 맞춤 비율에서 상대 차 점 빼기 (obstacle_detect.fit_without_obstacles)
- 원인: 맞춤 = 벽에 붙은 점 / 전체 점. 위치 찾기 (점수) 는 벽 점만 받아 차 점에 안 끌리지만, **비율** 은 차 점이 분모에
  들어가고 뒤 벽이 가려져 무너졌다 (161502: 0.88 → 0.04). obstacles off/watch/lidar 와 무관 (노드는 맵 고정 때문에 늘 돎).
- 방법: 같은 스캔의 검출 후보 덩어리 (트랙 안, 벽에서 떨어짐, 크기 ≤ 0.8 m = 기존 max_size) 주변 점 (반지름 크기/2 + 0.10) 을
  분모에서 뺀다. 안전장치: 빼는 점 > 45 % 면 안 뺌, 남은 점 < 30 이면 안 뺌, **뺀 뒤 맞춤 < 0.90 이면 원래 값**.
- 합성 시험 (실제 맵 track2a·track1a, 트랙 16 곳 × 상대 앞 0.6/1.0/2.0 m, 레이캐스팅):

| 경우 | 끔 (중앙 / ≥0.8) | 켬 |
|---|---|---|
| 상대 0.6 m 앞 (점 36 %) | 0.66 / 0 % | **1.00 / 100 %** |
| 상대 1.0 m | 0.87 / 100 % | 1.00 / 100 % |
| 위치 0.3 m·6° 틀림 | 0.66 / 23 % (1a 31 %) | 0.66 / 25 % (31 %) |
| 위치 0.5 m·10° 틀림 | 0.43 / 0 % | 0.43 / 0 % |
| 틀림 0.3 + 상대 | 0.57 / 8 % (15 %) | 0.57 / 23 % (25 %) |
| 틀림 0.5 + 상대 | 0.38 / 0 % | 0.38 / 2 % (4 %) |

  (0.90 문턱 없이 45 % 상한만이면 틀림 0.5 가 2~8 % 로 부풀었음 → 문턱 추가.) 기존 test_obstacle_detect (track2a) 모두 통과.
  계산 5.14 → 5.33 ms/스캔.

## 2. 흡수 버림 규칙 (lidar_bridge)
- 흡수 ≥ 1 m 또는 ≥ 20°: 맞춤이 나빠도 **버리지도 풀지도 않음** (경고 5 s 마다). 복구는 사람이 2D Pose / LT (036a8cf 로 흡수 비움).
- 작은 흡수: 버리기 전 3 s 기다림 (전엔 1 s). 그 사이 보정도 그대로.
- 흡수 없음: 전과 같음 (1 s 뒤 풀기 시작).
- 단위 시험 (맞춤 0.05 가림): 6.7 m·88° → 2 s·4 s 모두 유지 / 0.5 m·6° → 2 s 유지, 4 s 버림 / 없음 → 1 s 뒤 풀림.
