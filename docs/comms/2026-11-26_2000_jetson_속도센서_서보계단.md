## 1·2 속도 상태 — 넣음 (main, 젯슨)
- `mocap_bridge`: `vel_source: sensor` (기본) → vx = `/sensors/core` erpm ÷ 4781.5 × 1.044, r = `/odometry/filtered` 자이로
  (wheel_odom, 바이어스 뺀 값), 뒤축 vy = `vy_mode: zero` (기본, rot·kf 선택 가능). 각 성분 0.1 s 끊기면 그 성분만 KF.
  위치·yaw 는 그대로 mocap KF. `vel_source: kf` 면 예전과 같음.
- KF 속도는 `/mocap/kf_twist` 로 따로 → data_logger 끝에 `kf_vx, kf_vy, kf_r` 열 (지금 vx_kf·vy_kf·yaw_rate_kf 열은
  이제 '/mpc/state 에 실제로 들어간 값' = 센서 값이니 이름에 주의).
- `drive.sh` 가 mocap 주행에서도 wheel_odom 을 띄운다 (전엔 lidar 에서만).
- 단위 시험 (가짜 원운동 v 2, r 1): 센서 경로 vx 2.000·vy 0·r 1.000, 센서 끊긴 뒤 KF 로 넘어감. 실차 확인 전.
- MPC 쪽은 그대로: make_state 가 무게중심 vy = 뒤축 vy + lr·r.

## 3 서보 계단 응답 — 도구 준비 (`./drive.sh servostep [/wheel/pose]`, tools/servo_step.py)
- 거치대, 속도 0, `/commands/servo/position` 에 직접 50 Hz (노드의 3.2 rad/s 묶음 없이 물리 서보만).
  0 → +0.2 → 0 → −0.2 → 0 → +0.4 → 0 → −0.4 → 0 rad (각 1.5 s) × 3.
- 앞바퀴에 강체 (마커 3 개, 허브 바깥) 를 하나 더 만들면 실제 조향각 = 바퀴 yaw − 차체 yaw 로 계단마다
  순수 지연·10→90 %·최대 각속도·최종 각을 계산해 찍는다. 강체가 없으면 명령만 (영상용).
- 결과 csv: `~/mlcs_data/servostep_<시각>.csv` → 재면 data/timing 에 올림.
