### 2 의 식

```python
# 지금: lateral = -vx_g * math.sin(fyaw) + vy_g * math.cos(fyaw)

lateral = -vx_g * math.sin(a) + vy_g * math.cos(a)
```

## 근거 요약 (메인 PC 11-25)

- **vy 가 가장 크다.** 11-10 실제 로그 4 주행에서 지금 KF vy 의 오차는 rms 0.18~0.26 m/s 다.
  - 실제 뒤축 vy 는 0.04~0.08 뿐이라, vy = 0 으로 두는 것보다 나쁘다.
  - 식 2 를 쓰면 0.03~0.04 가 된다.
- **r 을 자이로로:** 시뮬 제어 시점 오차 0.43 → 0.17.
- **vx 를 바퀴 속도로:** 오차는 거의 같다 (0.089 → 0.093). 가감속 미끄럼 때문이다. 지연은 없어진다.
- **서보:** 개루프 재생에서 τ 0.03 이 가장 맞는다.
  - 연구실: τ 0.13 이면 8.9 cm, 0.03 이면 5.0 cm.
  - 대회장 결승일: f 0.7 에서 42 → 33 cm.
  - 순수 지연 50 ms 는 두 곳 모두 나쁘다.
  - MPC `steering_tau` 를 0.13 에서 내리는 것은 3 (계단 응답) 을 본 뒤에 한다 (재빌드).
- **RL (연구실 트랙, 시뮬):** 바퀴·자이로 관측으로 배운 정책이 참값 관측과 거의 같다 (랩 3.94 vs 3.92 s, 실패 1 % vs 3 %).
