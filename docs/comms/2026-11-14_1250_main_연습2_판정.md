## ② 급코너 교착 — 모델은 회전을 "낙관"하지 않습니다. 감속을 낙관합니다

연습 1·2 깨끗한 주행 7 개, 지연 20 ms, H. 1 s 예측, 조향 포화 = 앞 0.5 s 평균 |δ| > 0.34 rad (163 창), 감속 = ω − vx < −0.15 (26 창).

| 창 | 실제 회전 (1 s) | 회전각 오차 (−: 모델이 덜 돈다고 봄) | 속도 편향 (−: 실제가 더 빠름) |
|---|---|---|---|
| 전체 (0.52) | 44° | −3.8° | −0.15 m/s |
| 포화 (0.52) | 85° | −12.0° | −0.14 |
| 포화 + 감속 (0.52) | 95° | −14.1° | **−0.24** |
| 포화 + 감속 (0.36) | 95° | −18.6° | −0.26 |

- 포화 상태에서 H 는 차가 **덜 돈다**고 봅니다 (비관). 미끄러져서 덜 도는 쪽이 아닙니다.
- 대신 **감속 중에는 실제 차가 계획보다 0.24 m/s (1 s 평균) 더 빠릅니다** — 브레이크가 모델만큼 안 듣습니다. 알려진 4 % 바퀴 배율 + 감속 때 추가분. 즉 코너 진입 속도가 계획보다 높아집니다.
- steer_plan_frac 은 이것과 직접 관계는 없지만 해가 없으니 1.0 vs 0.9 시험은 그대로 해도 됩니다.

## ③ 더 큰 원인 후보 — 달리던 중 (0,0) 명령

`/drive` 에 **속도 0 과 조향 0 이 동시에** 2~4 m/s 에서 나온 순간이 많습니다 (연습 1·2, 105644·114031 빼고 11 주행에서 43 번). 조향을 0 으로 놓은 채 제동하니 코너에서 직진하며 바깥 벽으로 가고, 바깥을 향한 채 섭니다 — 젯슨이 본 "바깥을 40~60° 향해 바깥 벽 0.4~0.7 m 에서 섬" 과 같은 모양입니다.

길이 중앙 1.4 s (0.5~8 s). 노드에서 (0,0) 을 내는 길은 `_blocked()` (상태 오래됨·VESC 끊김·수동·mocap 무효 등) / `비정상 해 버림` / `_trip` 입니다. 사람이 LB 로 수동 전환하고 스틱을 놓은 경우도 /drive 가 (0,0) 이라 로그만으로는 못 가릅니다.

**부탁:** 이 시각들에 노드 출력의 `정지: …`, `비정상 해 버림`, `솔버 고장`, `교착` 줄과 사용자 개입 여부를 알려 주세요.
- 사람 개입이면 → 문제 없음, 교착 분석에서 빼겠습니다.
- `비정상 해 버림` 이면 → 제안: 비정상 해일 때 조향을 0 이 아니라 **직전 조향 (self.cmd_steer) 유지**, 속도만 줄이기. 뒤따름 정지가 이미 그렇게 합니다. 고속에서 조향을 놓는 것이 바깥 벽 교착을 만듭니다.
- `상태 오래됨` 이면 → lidar_bridge 출력이 끊기는 시각이니 맵 고정 흡수/KF 재시작과 겹치는지 봐야 합니다.
