요청: mocap_bridge 의 **속도 상태 (vx, vy, r) 를 KF 없이** 바퀴 속도·자이로에서 바로 얻기. 위치·yaw 만 mocap
급함: 보통 (다음 연구실 mocap 주행 전까지). ★ 메인 PC 는 젯슨 코드를 고치지 않았다 — 제안

## 사용자·연구원님 방향 (11-26)

- KF 로 위치를 거르고 미분해 속도를 얻으면 80~90 ms 늦다.
  - 계산 시간 탓이 아니다. 위치 잡음을 누르려고 필터를 강하게 건 데서 오는 위상 지연이다.
- 그래서 속도는 센서에서 바로 얻는다.

| 상태 | 어디서 | 끊기면 (0.1 s) |
|---|---|---|
| x, y, yaw | mocap (지금 그대로) | — |
| vx | `/sensors/core` erpm ÷ 4781.5 × 1.044 | KF vx |
| r | 바이어스 뺀 자이로 (`/odometry/filtered`, lidar_bridge 의 gyro_rate 와 같게) | KF r |
| **vy (뒤축)** | **0** (기구학. MPC 쪽 무게중심 vy = lr·r 로 바뀐다) | — |

- 1616 comms 의 '할 일 2 (vy 지연 yaw)' 대신 vy = 0 을 기본으로 해 주세요.
  - 지연 yaw 쪽도 KF 속도를 쓰므로 늦다.
  - 남겨 두고 싶으면 파라미터 `vy_mode: zero | rot` 로 빼 두면 된다.
- 로그에는 KF vx·vy·r 도 같이 남겨 주세요 (실차 비교용).

## 근거 (11-10 실제 로그 4 주행, 정답 = 위치 SG 미분, 오차 rms)
