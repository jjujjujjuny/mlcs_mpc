## ① 중앙선 가중치를 실차에 넣는 법

지금 젯슨은 q_n·q_mu 를 설정에서 받지 않는다 — `hypermpc/offline_ocp.make_cfg` 의 기본값 (논문 값) 이 그대로 들어간다. q_delta 와 같은 길로 넣으면 된다.

```python
# src/mlcs_mpc/mlcs_mpc/hmpc_node.py
d('q_n', 0.02)        # ★ 기준선 횡오차 n² (논문 0.02, 중앙선 5.0). 생성 코드에 들어간다
d('q_mu', 0.002)      # ★ 기준선 헤딩 오차 mu² (논문 0.002, 중앙선 1.0)
#   338 행 worker 설정에 q_delta 옆으로:  q_n=float(gp('q_n')), q_mu=float(gp('q_mu')),

# hypermpc/ocp_worker.py 136 행 아래
cfg['q_n'] = float(c.get('q_n', cfg['q_n']))
cfg['q_mu'] = float(c.get('q_mu', cfg['q_mu']))
```

```yaml
# race.yaml hmpc:
  q_n: 5.0              # ★ 중앙선 (11-27 결정). 논문 MPCC 로 돌리려면 0.02
  q_mu: 1.0             # ★ 중앙선. 논문 0.002
```

- make_solver 의 빌드 stamp 가 cfg 전체 해시라 자동으로 다시 빌드된다 (첫 실행 ~20 s)
