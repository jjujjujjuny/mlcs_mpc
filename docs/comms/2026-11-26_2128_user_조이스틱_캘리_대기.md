## 결론

트리거 캘리가 느린 게 아니라 **첫 조이스틱 입력이 오기 전에는 시작하지 않는다.** `_calibrate_rest` 는 `/joy` 20 개를 모아야 끝나는데, 입력이 한 번도 없으면 `/joy` 가 오지 않는다 (`autorepeat_rate: 20` 이어도). 화면은 "RT 에서 손 떼고 가만히 두세요" 라서 사용자는 손을 안 대고 기다리고, 그동안 캘리는 0 개에서 멈춰 있다.

## 제안 (젯슨이 판단)

1. **안내 문구만 바꾸기 (가장 간단):** "RT 에서 손 떼고 **왼쪽 스틱을 한 번 움직였다 놓으세요**" — 스틱은 조향 축이라 트리거 휴지값에 영향이 없다. LB 는 모드가 바뀌니 안내에 쓰지 말 것.
2. **입력 없이도 끝내기:** 몇 초 안에 샘플이 안 오면 ROS joy 표준 (휴지 +1, 당김 −1) 으로 정하고 진행. 11-26 세 번 모두 +1.000 이었다.
   - 주의: `joystick_teleop.py` 363 줄 주석대로 처음 건드리기 전에는 트리거 축이 0 으로 온다. 메시지 하나로 판정하면 0 을 휴지로 보고 '휴지≈0 (커널 드라이버)' 로 잘못 정할 수 있다.
3. 캘리 진행 상황 (모은 개수) 을 화면에 보여 주면 멈춘 건지 도는 건지 알 수 있다.
