주행: 145229 (v2.5), 145630 (v4.0), 145822 (v3.0), 150403 (v2.8). wall_margin 0.38 / 안쪽 0.48 / 바깥 0.28.
사용자: "코너는 확실히 안전, 직선에서 벽 긁음".

## 결과
- 코너: 차 모서리 벽 안 0~1.1 % — 비대칭 여유 효과 확인.
- 자이로: 정지 요레이트 중앙값 0.000, 주행 중 자이로−라이다 ±0.002 rad/s → 이번 4 주행은 바이어스 정상.
- **직선 긁힘 4건 모두 위치 튐과 겹침** (라이다 자세 vs 4 s 전부터 이어 붙인 바퀴·자이로 오도메트리):
  - 145229 t164: 0.9 m/s 에서 좌우 오차 +0.08→+0.33 m (2 s) 흐르다 2.2 m·20° 튐
  - 145630 t24: 4.0 m/s, 좌우 +0.30 (0.5 s) → +0.66 → 1.2 m 튐 → 사용자 정지
  - 145822 t76: 3.0 m/s, 좌우 +0.14→+0.72 (2 s), yaw 11° → 튐 / t240: +0.2→+0.66 (2.5 s) → 튐
  - 150403 t110 (정지 중 1.1 m), t137 (정지 중 0.8 m·27°)
- lidar_bridge 로그 (150403): 맵 고정 보정이 5 s 마다 ±30~60 cm 씩 바뀜 (맞춤 0.95~1.00) = Cartographer 자체가
  계속 0.5~1 m 흐름. "Cartographer 129 cm·23° 튐" 흡수, 이후 맞춤 0.25~0.42 로 떨어져 핀 풀림 → Cartographer 그대로.
  → 메인 PC 의 C 결론 (시간 누적 흐름) 과 같은 방향.

## 조치 (지금 적용, 사용자 주행으로 확인 예정)
1. `loc_odom: strict` 새 선택지 (race.yaml 기본으로 켬, 패널에서 ekf 로 되돌림 가능)
   `localization_2d_odom_strict.lua` = ekf 판 +
   odometry_translation/rotation_weight 1e4, global_constraint_search_after_n_seconds 1e6,
   fast CSM 창 1.5 m·30° → 0.5 m·10°, constraint_builder.min_score 0.65.
   Cartographer 기동만 시험 (설정 읽힘). 벤치 손 밀기 시험은 못 함 — 주행으로 바로 확인.
2. wheel_odom 바이어스 다시 잡기 (메인 긴급 제안 그대로): 서 있는데 2 s 넘게 게이트 밖 + 표준편차 < 1°/s 면
   그 평균으로. 단위 시험: 첫 샘플 77°/s → 3 s 뒤 0.32 로 복구, 손으로 흔든 것은 안 배움.

## 메인 PC 에 부탁
- 다음 주행 로그 (strict) 가 올라오면 같은 방식 (라이다 − 오도메트리 좌우 흐름, 튐 횟수) 으로 ekf 4 주행과 비교.
