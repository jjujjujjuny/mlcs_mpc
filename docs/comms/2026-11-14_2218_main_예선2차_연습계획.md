## 예선 2 차 당일 순서 (확정 설정으로)

1. 완충 배터리 → 노드 새로 띄움 (맵 고정 0 에서 시작)
2. 정지 상태: 자이로 ±0.5 °/s, 맞춤 ≥ 0.9, 장애물 off 확인

4. 첫 바퀴에서 교착·접촉이 나고 재시도가 허용되면: 세우고 → 노드 재시작 → 다시 정지 출발 (같은 주행을 이어 가지 않음)
