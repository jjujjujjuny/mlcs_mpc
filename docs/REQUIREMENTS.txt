mlcs_mpc — 요구사항 정리 (2026-11-24)
================================================================
지금까지 정해진 요구사항·제약을 한 곳에 모았다. "근거" 는 그 요구가 나온 곳 (문서·실측·요청).
상태: [완료] 구현·시험됨  [부분] 일부만  [미정] 아직  [실차X] 시뮬에서만 확인 (README 검증 표 기준)


1. 시스템
----------------------------------------------------------------
R1.1  차: F1TENTH, Jetson Orin Nano (Ubuntu 22.04, ROS 2 Humble), VESC 6, 서보, 3S 배터리.
R1.2  위치추정: 연구실 = OptiTrack mocap (100 Hz, 기준점 = 앞축 중심 위 강체), 대회 = LiDAR + Cartographer.
R1.3  워크플로: PC 시뮬 (./sim.sh, main.py) 에서 튜닝 → 커밋 → 젯슨 (./race.sh). 둘 다 같은 race.yaml·mpcc.yaml.
R1.4  주기: MPC 30 Hz (OCP dt 0.033 s, N 60), 풀이 p95 ≤ 33 ms (실측 젯슨 약 21 ms), VESC 속도 PID 1 kHz.   [완료]
R1.5  문서·주석·커밋·CLI 출력은 한국어.


2. 안전 (모든 노드)
----------------------------------------------------------------
R2.1  발행을 멈춰도 차는 서지 않는다 (VESC 가 마지막 속도 유지) → 모든 실패 경로가 속도 0 을 직접 발행.   [완료]
R2.2  /mpc/enabled 가 true 가 되기 전에는 움직이지 않는다 (./drive.sh go / halt).                       [완료]
R2.3  acados 풀이는 별도 프로세스 (NaN 에서 멈출 수 있음). 시간 초과면 SIGKILL, 속도 0, enabled false→true 까지 고장 래치. [완료]
R2.4  조이스틱 끊김이면 속도 0 (mux 우선순위 조이스틱 100 > 내비 10).                                    [완료]


3. 제어기 (MPCC)
----------------------------------------------------------------
R3.1  MPC 설정값은 config/mpcc.yaml (→ race.yaml mpcc: → --config → --set) 에서만. 다른 곳에 하드코딩 금지.
R3.2  차 모델은 env/vehicle_model.py 하나 (MPC·시뮬·RL 공통). 바꾸면 env/vec/vehicle.py 도 같이 (test_vec_vehicle).
R3.3  학습 파라미터 모델은 env/mpc/param_model.py 인터페이스로만 붙인다 (기본 ConstantParams).
R3.4  플랫폼 차이는 utils/runenv.LIB_PATH_VAR, acados_solver.LIB_EXT 로 (LD_LIBRARY_PATH·.so 하드코딩 금지).


4. ODE 시뮬레이터 (2026-11-24 요청)
----------------------------------------------------------------
R4.1  상위 → 저수준 → 동역학 3 계층 (f1tenth_gym 과 같은 구조). /drive 목표 (δ_ref, ω_ref) 는 저수준 제어기를
      거쳐 (조향 각속도·바퀴 가속도) 적분된다. 저수준은 적분 안에서 더 세밀하게 (RK4 1 ms 단계마다) 계산한다.
      느려져도 된다.                                                                                 [완료] env/lowlevel.py
R4.2  저수준 파라미터는 나중에 고칠 수 있게 파일로: config/lowlevel.yaml, --lowlevel KEY=VALUE.        [완료]
R4.3  저수준 종류: 조향 lag | gym(뱅뱅) + 각속도 한계 + 지연, 속도 lag | gym(P) + 가속·감속 한계 + 지연,
      wheel_model vesc = 펌웨어 속도 PID·전류·제동 (env/drivetrain.py).                                [완료]
R4.4  기본값 (LowLevelConfig()) 은 예전 시뮬레이터와 같은 결과 (회귀 시험 차 0).                       [완료] test_simulator
R4.5  공용 차 모델 식은 바꾸지 않는다 (u = x + τ·ẋ 로 저수준 출력을 넣는다).                            [완료]
