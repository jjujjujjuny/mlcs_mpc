## 찾은 문제와 고친 것 (순서대로)

1. **`wall_bounds` 버그 (`hypermpc/offline_ocp.py`, 실차 `ocp_worker` 도 같은 함수)**
   relax 식 `min(lo, n0·f)` 가 f → 0 이면 n = 0 (트랙 선) 을 늘 허용했다. 벽은 0 이 늘 안쪽이라 티가 안 났지만,
   0 을 막는 추월 통로 (예: n ≤ −0.40) 는 10 스테이지 뒤부터 n ≤ 0 으로 풀려 **통째로 무시**됐다.
   → `lo + min(n0 − lo, 0)·f`, `hi + max(n0 − hi, 0)·f`
2. **뒤따르기 속도 상한 (`opponent.trail_cap`)**: 예전엔 지금 간격 하나로 `v_상대 + 1.0 × (간격 − 0.8)` 을
   모든 스테이지에 같게 줬다. MPC 가 앞에서 서야 함을 못 보고, 바퀴 시정수 0.4 s 와 맞물려 0.2 m 까지 붙었다.
   → 스테이지별 예측 간격으로 `v_상대 + √(2·0.6·e)`, `e = 간격 − 목표 − 0.4 s × 우리 속도`, 가까우면 `1.0 × e`,
   바퀴 속도로 바꿀 때 `× (1 − nκ)` (코너 안쪽은 같은 바퀴 속도로 s 가 더 빨리 간다)
3. **커브 안쪽 도달성 (`plan(..., kappa)`)**: 커브를 도는 데 이미 쓰는 곡률만큼 안쪽으로 비키는 여유가 줄어든다.
   예전엔 무시해서, 조향 포화인 채 못 비키는 추월을 고르고 그 자리에 섰다
4. **추월 중 감속 (`pass_guard`)**: 옆으로 아직 못 비켰으면 상대 0.70 m 앞에서 설 수 있는 속도까지만.
   1109_3 가운데 정지 상자 (441 주기 충돌) 는 오른쪽 통로를 골랐는데 못 비킨 채 2 m/s 로 가다 1.4 m 앞에서 포기했다
5. **통로가 벽을 넘지 않게 (`apply_corridor`)**: 넘으면 솔버가 lo > hi 를 가운데 점으로 두는데 그 점이 벽 밖이다
6. **뒤따름 정지는 이미 느릴 때만 (노드 `trail_stop_vx` 0.5, offline 같게)**: 상한이 0.3 아래면 풀지 않고 조향을
   고정한 채 세웠는데, 1.3 m/s 로 커브를 돌던 중이라 벽 밖으로 미끄러졌다 (벽 밖 86 %, 60° 로 갇힘)
7. **목표 간격은 천천히 늘린다 (`standoff_rate` 0.5 m/s)**: 0.8 → 1.3 m 로 훅 바뀌어 상한이 1.3 → 0 으로 떨어졌다.
   (처음엔 상한 자체에 감속 하한을 걸었는데, 바퀴 지연과 겹쳐 실제 감속이 0.5 m/s² 밖에 안 돼 앞차에 붙었다 → 되돌림)

## 시뮬레이션 (`hypermpc/offline_ocp.py`) 에 더한 것

- `--recover-reverse` 조건을 노드와 같게: 뒤따름·뒤따름 정지 중에는 교착으로 안 보고, 상대가 뒤 1 m 안이면 후진 안 함
  (요약에 횟수), 같은 자리 3 번 (노드 recover_tries) 이면 래치 (전엔 2 번)

- **GP 다시 맞추기를 1 Hz 로 부른다.** 노드는 타이머로 부르는데 offline 은 안 불러서, 지금까지 오프라인 시험은
  전부 GP 없이 (제로샷) 돌았다. 다시 맞추기 평균 15 ms, 최대 36 ms (노트북)
- 현실적인 가상 상대: `--opp-alat A` (코너에서 √(A/|κ|) 로 줄임), `--opp-weave W` (라인 ± W, 한 바퀴 두 번),
  `--opp-no-gp`
- 요약에 1 s 앞 예측 오차 (제로샷/GP), GP 사용 비율, 평균 속도, '뒤박힘' (가상 상대는 피하지 않아 서 있는 우리를
  뒤에서 박는다 — 우리 탓 충돌과 나눠 본다)
