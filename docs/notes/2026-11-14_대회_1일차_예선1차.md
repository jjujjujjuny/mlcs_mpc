- **트랙 선택이 목표를 따라가야 한다.** 랩 수 → 위치추정이 건강한 트랙, 랩타임 → 빠른 트랙
- **기록 랩은 바퀴 거리로 확인한다.** 17.0 s 는 위치 튐이 결승선을 넘은 것이었다 (바퀴 거리 51.6 m, 한 바퀴 57.5 m)
- **"튐" 을 보면 먼저 사람이 다시 찍은 시각과 맞춰 본다.** 170753 의 180° 튐을 Cartographer 탓으로 잘못 결론냈다
