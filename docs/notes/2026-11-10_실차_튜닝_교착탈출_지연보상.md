## 3. 교착 탈출 후진 (`recover_reverse`)

**문제**: 급코너 안에서 코너 바깥을 향해 서면 어떻게 가도 경계를 넘어서 MPC 가 서 있기를 고른다 (명령 0.26 → 0.01). mocap 후보 모델 출발에서 처음 봄 — 모델 차이가 아니라 출발 자세 (s 0.58, κ 1.81, μ −24°). offline 재현: 급코너 −25° 5 자세 중 3 교착.

**동작** (노드, MPC 밖):
- MPC 로 달리는데 1 s 동안 0.1 m 도 못 가고 평균 vx < 0.15
- 조향 sign(μ)·최대 (후진은 요 방향이 반대 → 헤딩 차가 준다), 1.2 m/s 로 0.4 m (최대 1.2 s) 후진 → 정지 → 초기 추측 다시 깔고 MPC
- 같은 자리 (s 0.5 m) 3번이면 고장 래치. 1 m 넘게 나아가거나 사람이 개입하면 횟수 초기화
- 후진 중·끝난 뒤 1 s 는 '후진 중' 정지 안 걸음. bench·상대 뒤따름 중엔 안 함

**실차**: 처음 0.45 m/s·0.8 s 는 3~10 cm 뿐이었다 (정지에서 모터가 늦게 돎). 횟수 기록이 지워지지 않아 B 재출발 뒤 곧바로 래치되던 버그도 고침. 1.2 m/s·0.4 m 로 바꾼 뒤 한 주행 11번 모두 0.40~0.43 m 후진 후 복귀, 래치 0. 대회 규칙상 후진 허용 (사용자 확인).

## 4. 지연 보상 (`delay_comp`, `delay_extra`, `act_delay`)

**구조**: 노드가 상태 스탬프와 내보낸 명령 8개 (실제 조향각·바퀴 속도) 를 워커에 보내고, 워커가 풀기 직전 x0 를 (나이 + 풀이 EMA + `delay_extra` + `act_delay`) 만큼 그 명령으로 적분해 당긴다. 상한 0.2 s. 예측 적분은 casadi 함수 하나 (`offline_ocp.make_step`, 스텝당 0.19 ms — 파이썬 반복은 1.4 ms 라 100 ms 예측에서 노드가 15 Hz 로 떨어졌었다).

**지연 측정**
- 라이다: `recv − stamp` 5~6 ms — Cartographer 가 자세를 발행 시각으로 외삽해 찍어 스탬프로는 지연이 안 보인다. 주행별 라이다↔mocap 상관 지연 17~27 ms (맵 정렬 time_lag 는 재현 안 됨: 1109_3 정렬 51 ms vs 주행별 6~27) → `delay_extra` 라이다 고정 0.025 (`race.sh` 자동)
- 조향: 명령 → 실제 곡률 (L·r/vx) 지연이 실차 187 ms vs offline (H 모델) 107 ms → 미모델 66~80 ms. 이 몫에는 mocap 측정 지연 (스탬프 = 젯슨이 받은 시각, KF) 이 섞여 있을 수 있다

**offline (1108_7 v2.0 q_δ 3)**: 차에 70 ms 명령 지연을 넣으면 실차 모습이 재현된다 (명령→곡률 98 → 169 ms, 0.5~2 Hz 12 → 20%, 랩 5.10/0.02 → 5.18/0.06). `act_delay` 0.07 보상으로 9%, 5.12/0.02 로 회복. 모델 불일치 (차 = 원래 H, 바퀴 τ 0.3) 와 지연 흔들림 (80±20 ms) 에서도 효과 유지.
