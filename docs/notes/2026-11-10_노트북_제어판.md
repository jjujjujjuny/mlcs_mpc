## 방법과 결정

- **참고**: 다른 팀 레포(ixiivi/YAX3_F1T_TEAM2, MAGP 브랜치)의 PyQt5 제어판은 젯슨 화면에서 돌리고 RustDesk 로 본다. 맥용 원격 설계 문서(서버 주도 UI, NDJSON over SSH 터널, 서버가 E-STOP·데드맨 소유)는 있으나 구현은 없었다. 우리는 이미 Zenoh(보기)·SSH+tmux(명령)가 있어서 노트북 PyQt5 하나 + 젯슨 셸 스크립트 하나로 했다
- **젯슨 부하가 최우선** (사용자: 솔버 시간이 늘면 안 하는 게 낫다)
  - 조회 명령은 코어 0-3·nice 19. 젯슨에 isolcpus 가 없어 그냥 두면 솔버 코어 5 에 올라갈 수 있다
  - `status` 첫 버전 0.28 s CPU (pgrep 7 번 = /proc 7 번 훑기) → 프로세스 목록 한 번 + awk 한 번 + 서브셸 없이 0.055 s
  - ★ 실행 명령(start)에는 nice·taskset 을 물려주지 않는다. tmux 서버가 nice 19 로 뜨면 hmpc·솔버가 최저 우선순위가 되고 root 없이 못 되돌린다. 제어판으로 띄운 race.sh 가 nice 0·코어 0-5 인 것 확인
  - SSH 비대화형 실행에서 젯슨 `.bashrc` 는 첫 줄에서 돌아가 ROS source 비용이 없다
- tmux 로는 '돌고 있음' 과 '끝나고 프롬프트만 남음' 이 구분되지 않는다 (`pane_current_command` 둘 다 bash) → 명령이 끝나면 `/tmp/mlcs_panel_mode` 에 `ended`
- 명령어 탭은 스크립트 맨 위 사용법 주석을 그대로 읽는다 (문구를 옮겨 적지 않음). 제어판에는 '명령 이름 → 묶음' 표뿐, 새 명령은 '기타' 로
