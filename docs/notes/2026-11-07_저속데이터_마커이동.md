## 연구 진행 상황

### 동정 모델 정확도와 저속 데이터

**1초 예측** (모델에 실제 입력을 넣고 1 s 굴림, 윈도 0.25 s 간격, 손실은 학습과 같은 정의)

| 데이터 | 평균 속도 | 손실 동정값 / 기본값 | 동정값 RMSE `v_x` / `v_y` / `r` |
|---|---|---|---|
| 학습 test (사람 주행) | 1.62 m/s | 0.0081 / 0.0376 | 0.093 / 0.067 / 0.138 |
| 자율주행 4개 (학습에 안 씀) | 0.68 m/s | 0.0037 / 0.0044 | 0.024 / 0.015 / 0.118 |

- 메인 PC 수치(0.0078)를 거의 재현했다
- 0.7 m/s 에서는 동정 효과가 작다. `r` 오차 0.118 rad/s 는 이 구간 `r` 크기(중앙 0.48)에 비해 크다. 운동학 `v·tanδ/L` 의 즉시 오차는 0.132 rad/s (1초 예측과 같은 비교는 아니다)
- 모델이 `r` 을 평균 0.057 rad/s 작게 낸다. 실제 `r` / 운동학 `r` 은 1.01 이라 조향 맵 문제는 아니고, 저속에서 동정 모델의 언더스티어가 과한 쪽으로 보인다 (원인 미확정)
- 서보 순수 지연(약 0.08 s)이 모델에 없어 조향이 바뀌는 순간의 오차가 섞여 있다
- 학습 데이터의 0.5~0.8 m/s 비율이 2.7% (조향 0.2 이상 1.0%) 뿐이었다. 자율주행은 98% 가 이 구간이다

**저속 데이터 수집** (`./drive.sh rally`, 11-07, 3개 로그 708 s, 정리 후 703 s)

0.6, 0.7, 0.8 m/s × 조향 ±0.20, ±0.30, ±0.38 모든 조합을 20~33 s 씩, 조향 계단 약 10회. mocap 끊김 0.

- **조향 맵 확인**: 실제 조향 / 맵 예상 0.98~1.06. ±0.38 에서 1.005~1.049 로, offset 변경 뒤 최대 조향 약 0.378 rad 가 맞다 (다시 잴 항목이던 것)
- 저속에서 실제 회전 반경은 운동학과 맞는다. 명령 0.6 m/s 에 실제 0.50~0.61 m/s, 많이 꺾을수록 느리다

**학습 데이터**: `hpm_data_20261107` (44분). 이전 33분은 그대로 두고 (`run_id` < 10000) 새 10.8분을 따로 나눠 붙였다. 0.5~0.8 m/s 비율 25.8%. 이 데이터로 재동정은 아직 안 했다.

### 마커를 라이다 위로 옮김

라이다를 쓰려고 앞쪽 Y자 지그의 마커를 떼고, 라이다 위에 마커 6개를 비대칭으로 붙였다. Motive 에서 강체 `car` 를 새로 만들고 Orientation 을 Reset to Current 로 맞췄다.

| 단계 | `offset_x` | `offset_y` | `yaw_offset` | 근거 |
|---|---|---|---|---|
| 옮기기 전 | −0.33 | 0 | −0.014 | 앞축 Y자 지그, 11-05 원선회 |
| `yawcal` (Pivot 기본값) | 0 → 측정 −0.11 | −0.034 → 측정 0 | 0 → 측정 +0.141 | 옆 미끄러짐 +7.98~+8.17°, 보고 위치가 뒤축보다 약 11 cm 앞 |
| **최종** (Pivot 을 뒤축 위 마커로 지정) | **0** | **−0.034** | **+0.062** | 아래 확인 주행 |

`mocapcal spin` 은 잔차 320 mm, 산포 ±0.31 m 로 쓰지 않았다. 대신 원선회(`./drive.sh rally`, 조향 ±0.30)의 정상 상태에서 계산했다:
- yaw: 뒤축 옆 미끄러짐의 좌우 평균
- 앞뒤 위치: 옆 속도 대 요레이트 기울기 (기준점이 앞에 있으면 `v_y = d·r`). 저속일수록 정확하다
- 좌우 위치: 좌우 회전의 속도 대 바퀴 속도 비 차이 (`v = v_축 − e·r`)

**확인 주행 `yawcal2`** (`offset_x 0`, `offset_y 0`, `yaw_offset 0.141` 상태): 앞뒤 +0.009 / −0.003 m, 좌우 왼쪽 +0.029 / +0.032 m (줄자 3.4 cm 와 맞음), 옆 미끄러짐 평균 −4.55 / −4.53° (0.6 / 1.0 m/s). Pivot 을 옮기면서 강체 방향도 약 4.5° 바뀐 것으로 보인다. `yaw_offset` 을 0.141 − 0.0792 = 0.062 로 고쳤다. 이 값 그대로 다시 달려 확인하지는 않았다.

`yawcal`, `yawcal2` 두 로그는 보정 전이라 `tools/prep_hpm_dataset.py` 의 `SKIP_LOGS` 로 학습에서 뺐다. 마커를 옮긴 뒤부터 이 보정 전까지 다른 로그는 없다.
