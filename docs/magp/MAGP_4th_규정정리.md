## 2. 클래스별 차량 규정

RoboRacer(구 F1TENTH) CDC2024 룰 준거 (https://cdc2024-race.f1tenth.org/rules.html).
3회 대회 기준 결승은 **전 클래스 공통 토너먼트(예선 상위 8팀)**.

### 2-1. RoboRacer class ← **우리**
| 항목 | 규정 |
|---|---|
| 섀시 | Traxxas Slash 4×4 Premium |
| ESC | VESC 6 MkV |
| 모터 | Velineon 3500kV **1개** |
| 배터리 | **3S LiPo 1개** |
| 2D LiDAR | **UTM-30LX 상당 이하**. 3D LiDAR 금지 |
| RGB(D) 카메라 | RealSense 상당 이하. **자기위치추정 내장 제품 금지** |
| 컴퓨터 | Jetson / NUC / 그 이하 → Orin Nano OK |
| 연산 | **차량 탑재 PC로만**. 외부 PC 연산 금지 |

### 2-2. MAGP class (타미야 기반, 일본 팀 주류)
- 타미야 TT-02/M 시리즈 또는 동급(차체 300–400mm, 휠베이스 ≥200mm), TBLE-04S/04SR, 540 브러시드 또는 T17.5↑ 브러시리스, 순정 타이어, 2S 상당 배터리.

### 2-3. Open class
- 차종 무제한(약 1/10), 3S·5000mAh 이하, 가동부 금지, **토너먼트·시상 제외될 수 있음**.

### 2-4. 공통 안전 요건 (차검) ⚠️
- [ ] **후방 식별 박스**: 폭 ≥12cm, 깊이 ≥12cm, **상단이 지면에서 ≥20cm**
- [ ] **범퍼**: 최소 전면 쿠션재. 과도한 쿠션 불가
- [ ] 충돌 시 **배터리에 직접 충격 안 가는 구조**
- [ ] **조이스틱으로 주행 시작 + 긴급정지**
- [ ] 고상대속도 충돌 예상 시 자발 감속
- [ ] 타이어: 자국 남는 연질·점착 금지, 순정 원칙. **지속 드리프트 금지**
- [ ] 속도용 하드웨어 개조·특수 기구 금지

### 2-5. 통신·원격 조작
- 허용: 시작/정지/긴급정지, 텔레메트리
- **금지**: 외부 연산 / **주행 중 원격 파라미터 변경**(긴급정지 제외) / 절대위치 센서(실내 GPS 등)
- 파라미터 변경은 **정지 후**에만 → 프리셋 전환 방식으로

## 3. 경기 방식

### 3-1. 코스
- 평평한 바닥 20–30m × 약 10m, **덕트(배관 커버)로 벽 구성**. 최소 폭 = 차량 약 3대
- **덕트 이음새로 LiDAR 빔이 새는 구간** → 스캔 필터 필요
- 바닥 단색 라인(중앙선·최적선 아님)
- 코스 형상은 당일 결정 → **현장 연습주행 중 맵 생성·적응** 전제
- (3회) 오른쪽 숏컷, **매우 미끄러운 판 2곳**

### 3-2. 예선 (타임 트라이얼)
- 팀당 **2회 × 5분 단독 주행** (3회는 4분×2)
- 기록: **① 베스트 랩, ② 무충돌 연속 랩 수** → 두 순위로 결승 대진
- 트랜스폰더 지정 위치 부착
- 충돌 후 재시작하면 다음 체크포인트 통과부터 카운트
- 5분은 계속 흐름. 정지 후 세팅 변경 가능

### 3-3. 결승 토너먼트
- **1:1, 떨어진 두 지점 동시 출발 → 먼저 10랩** (3회는 8랩). **3세트 2선승**
- 레이스 전 **기능 점검 최대 10분**: 장애물 회피/정지(수동 긴급정지 대체 가능) + 조이스틱 긴급정지. **불통과 즉시 탈락**
- 코스 충돌: 페널티 없음, 충돌 지점에서 재시작
- 차량 간 충돌로 주행 불가 → 중단 후 재시작
